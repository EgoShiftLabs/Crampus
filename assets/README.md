# Original CRAMPUS artwork recovery

The original 2025 Replit project is the source of truth. The new repo started without artwork.

The reconstructed gallery expects:

- crampus-main.png — original character art.
- crampus-dexscreener-banner.png — original 600×200-style banner.
- crampus-token-icon.png — original token / brand icon.

Known archive categories: Meme-Scenes, Cinematic, Holiday-Chaos, TikTok-9x16, Banners, DexScreener-600x200, Icons-Headshots, Transparent-Poses, Expression-Pack.

**To restore:** Export the source/assets from Replit, then upload these images to this folder. Gallery tiles will automatically display valid image files and hide the placeholder text. If the original names differ, either rename copies to the paths above or update the three references in index.html.

Keep the originals and metadata in a separate archival backup before changing them. Do not upload secret keys or private files.
