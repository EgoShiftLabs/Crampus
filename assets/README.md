# CRAMPUS 2026 — Artwork deployment manifest

This site is ready to display the four new CRAMPUS images regenerated from the original character video.

## Upload these four files to this assets/ directory

- **crampus-banner.webp** — 1536 × 512; cinematic wide masthead showing CRAMPUS beside the golden brand title.
- **crampus-character.webp** — 1122 × 1402; transparent full-body villain render in red velvet with ram horns and cane.
- **crampus-poster.webp** — 1122 × 1402; snow-covered Christmas street cinematic poster; lore and gallery.
- **crampus-icon.webp** — 1254 × 1254; close-up gold-rimmed portrait, used as favicon and gallery seal.

The 2026 artwork was provided by the founder in the ChatGPT project conversation, and converted into optimized WebP files. **It is not in this GitHub repository until these four binary images are actually uploaded.** The page currently has stylized fallback art and safely hides absent images.

### Upload steps

1. Download the prepared CRAMPUS_2026_Web_Assets.zip from the conversation and extract the four .webp files.
2. Open the assets directory in GitHub.
3. Use **Add file → Upload files**; upload the four .webp files, not the ZIP itself, and commit to main.
4. Once published, the billboard, hero image, lore poster, icon, and evidence locker auto-activate. There is no configuration or backend.

### Design intent

Character: horned ancient Christmas demon, glowing red eyes, white braided beard, crimson velvet coat, black fur, ornate gold accessories. Tone: a frightening mythological entity with incredibly petty modern-day humor.

The previous Replit project remains available separately, but its original code/images were not retrievable. This restoration deliberately runs as a static website without a database or paid server.

Never upload secrets, wallets, or API keys.
