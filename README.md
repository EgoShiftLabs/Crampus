## Publish on GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Choose **Deploy from a branch** under Build and deployment.
3. Select **main**, **/(root)** and **Save**.
4. Check https://egoshiftlabs.github.io/Crampus/ after the deployment succeeds.

Do not treat the target URL as verified live until GitHub Pages is enabled.

For a custom domain, verify you own it and then follow GitHub Pages domain setup; do not set a stale CNAME blindly.
